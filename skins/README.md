# Bundled skins (local only)

Put an `.osk` here as `default.osk` (or `Kori 3.0.osk`) and serve the folder over http
(`npx http-server .`). On first launch Ashtonk!mania imports it and selects it as the gameplay skin.

`.osk` files in this folder are git-ignored on purpose: skins belong to their authors, so they
aren't redistributed through this repository. You can always drag an `.osk` onto the window instead.
