# More of Neru's poses

Cut out of her song's music video with `tools/neru-art.py` like the ones in `public/`, but not shipped: each screen
shows one pose of its own (`NeruCameo.POSE`). To use one, move it into `public/`, give it a screen in `POSE` and its
head size in `NeruCameo.HEAD`:

| pose | head size |
|---|---|
| dance | 0.18 |
| knees | 0.45 |
| meh | 0.52 |
| phone | 0.31 |
| pointat | 0.32 |
| side | 0.37 |
| smirk | 0.53 |
| snicker | 0.21 |
| sulk | 0.45 |
| worried | 0.47 |
